# Parked ideas

Ideas written down so they are not lost, and so they do not become a distraction. We pick them up when the knowledge base actually needs them.

- **Instant definition**: press a key, say or type a word, release, and a popup shows a first definition, looked up in this knowledge base first. The word is added to `INBOX.md`. Leads: local transcription with Whisper (already used in Alambic), a global macOS shortcut.
- **Assisted verification**: for a given concept, Claude searches the reference sources, compares, and proposes a correction citing the exact source; I approve, and the page becomes `verified`.
- **Review**: feed pages into Alambic to generate Anki cards.
- **Automatic generation**: run `tools/generate.mjs` on every commit, with a Git hook.
- **Link checking**: a script, or a GitHub Action, that checks every link.
- **Concept map**: generate a Mermaid diagram of the links between pages, which GitHub renders natively.
- **Notion migration**: bring back here whatever in Notion belongs to the fundamentals.
