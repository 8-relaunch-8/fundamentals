# Journal

This folder is **private by design**: `.gitignore` keeps everything in it off GitHub, except this page.

- `YYYY/YYYY-MM-DD.md`: one page per day, written during the evening ritual from the [day template](../templates/day.md).
- `handoffs/`: one handoff per ongoing project, updated over time, from the [handoff template](../templates/handoff.md).

Whatever deserves to be public is never published from the journal: it becomes a concept, error or practice page instead.
