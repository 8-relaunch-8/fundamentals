# Reference sources

Where to look when writing or verifying a page, in order of priority.

1. **For a tool or a language**, the official documentation is authoritative: it defines what the tool does.
2. **For a concept**, rely on a public university course or a curriculum framework.
3. **Free reference books** come next.
4. **Wikipedia** is an entry point for finding sources, not a final source.

Mind the licenses: many courses are under a non-commercial license (CC BY-NC-SA). Read them, cite them, never copy them.

## Curriculum frameworks

- [CS2023](https://csed.acm.org/) (ACM, IEEE, AAAI): what a computer science degree covers.
- [SWEBOK](https://www.computer.org/education/bodies-of-knowledge/software-engineering) (IEEE): the software engineering body of knowledge.

## Public university courses and curricula

- [CS50](https://cs50.harvard.edu/) (Harvard): introduction to computer science.
- [MIT OpenCourseWare](https://ocw.mit.edu/): MIT course materials.
- [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) (MIT): the shell, Git, editors.
- [OSSU Computer Science](https://github.com/ossu/computer-science): a complete curriculum made of free courses.
- [Teach Yourself Computer Science](https://teachyourselfcs.com/): one reference book and course per subject.
- [FUN MOOC](https://www.fun-mooc.fr/): MOOCs from French universities and engineering schools.

## Official documentation

- [Git](https://git-scm.com/doc), and the [Pro Git book](https://git-scm.com/book/en/v2) (also available in French)
- [MDN Web Docs](https://developer.mozilla.org/): the web, HTML, CSS, JavaScript
- [TypeScript](https://www.typescriptlang.org/docs/)
- [The Rust Programming Language](https://doc.rust-lang.org/book/)
- [Apple Developer](https://developer.apple.com/documentation/): Swift, SwiftUI, iOS
- [Expo](https://docs.expo.dev/) and [React Native](https://reactnative.dev/docs/getting-started)
- [Zed](https://zed.dev/docs/)
