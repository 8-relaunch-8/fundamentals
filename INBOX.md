# Inbox

Jot a term down in five seconds, without deciding where it belongs. Sort it later.

Format: `- YYYY-MM-DD · term · where I saw it`

When sorting, each line gets exactly one outcome: a new page, an addition to an existing page, or nothing (the line is removed).
