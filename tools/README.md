# Tools

Scripts that keep the knowledge base alive.

- `generate.mjs` (coming soon): reads every page in `knowledge/`, extracts its title, English term, status and "En bref" line, then rewrites the generated glossary sections (each domain's README and `GLOSSARY.md`). It only touches what lies between the `glossary:start` and `glossary:end` markers.
